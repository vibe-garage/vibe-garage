What you build

  1. Start a clock: a Spawner (Node2D at 0, 0) in the arena with a SpawnTimer child (Timer, Wait Time 1 second, Autostart on), and its timeout signal connected to a new spawner.gd.
  2. Copy a crab: an exported PackedScene slot holding enemy.tscn, then instantiate and add_child each time the timer runs out.
  3. Wake each crab at birth: set its target to the first node in group player, the spark.
  4. From every edge: pick a random point on a circle around the middle of the screen, half the screen's diagonal plus a 64 px margin away, so each crab is born off screen.
  5. The missing crabs: print where they're born, and find the minus signs, crabs born outside the arena walls.
  6. Keep them inside: a FLOOR Rect2 and a while loop that only accepts points on the floor.
  7. Run the same swarm in a browser tab on your own computer.

Born off screen, on the floor (spawner.gd)

func spawn_point() -> Vector2:
	var center := get_viewport().get_camera_2d().get_screen_center_position()
	var radius := get_viewport_rect().size.length() / 2.0 + margin
	var point := Vector2.ZERO
	while not FLOOR.has_point(point):
		point = center + Vector2.RIGHT.rotated(randf_range(0.0, TAU)) * radius
	return point

What's in the folder

  • spawner.gd: new: the timeout callback and spawn_point()
  • arena.tscn: the Episode 3 arena plus Spawner › SpawnTimer
  • enemy.gd, enemy.tscn: the crab, unchanged from Episode 3
  • spark.gd, spark.tscn: the spark, unchanged from Episode 3

Run it

  1. Install Godot 4.8 beta 1 (the standard build).
  2. Unzip ep04.zip.
  3. In Godot's Project Manager, click Import and pick project.godot inside the spark-swarm-ep04 folder.
  4. Press Play (F5). Move with WASD, the arrow keys or a gamepad. Zap with Space or the bottom face button.

One honest limit: Nothing ever stops the count. Leave the game running, and after a minute there are sixty new crabs on the floor, and they never leave. Touching you still does nothing. Getting hurt comes in a later episode.
