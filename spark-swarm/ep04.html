Kill the last crab, and your arena is dead. This episode fixes that for good: a timer spawns a fresh crab every second, each one walks in from off screen, and they come from every edge of the arena.

What you build

  1. Start a clock: add a Spawner node to the arena with a SpawnTimer child. Tick Autostart, leave Wait Time at 1 second, and connect the timer's timeout signal to the Spawner.
  2. Copy a crab: an exported enemy_scene PackedScene on spawner.gd. Each time the timer runs out, instantiate a copy, set its target to the player so it wakes up at birth, and add_child it into the running game.
  3. Spawn from every edge: spawn_point() picks a random angle and steps out to a circle a little past the screen's corners (half the diagonal plus a 64 px margin), so every crab walks in from off screen.
  4. Hunt the missing crabs: let it run for 30 seconds and count. Half the crabs never arrive. Printing the spawn positions shows minus signs: they are being born outside the arena walls.
  5. Keep them inside: a FLOOR Rect2 marking the safe floor (corner 96, 96; size 2112 by 1088) and a while loop that keeps picking until the point lands on the floor and is still off screen.
  6. Set your own pace: Wait Time 0.2 spawns five crabs a second, and the floor fills fast. Set it back to 1 for one a second.
  7. Run the same endless swarm in a browser tab on your own computer.

The endless spawner (spawner.gd)

extends Node2D

@export var enemy_scene: PackedScene
@export var margin := 64.0

const FLOOR := Rect2(96, 96, 2112, 1088)

func _on_spawn_timer_timeout() -> void:
	var crab := enemy_scene.instantiate()
	crab.position = spawn_point()
	crab.target = get_tree().get_first_node_in_group("player")
	add_child(crab)

func spawn_point() -> Vector2:
	var center := get_viewport().get_camera_2d().get_screen_center_position()
	var radius := get_viewport_rect().size.length() / 2.0 + margin
	var point := Vector2.ZERO
	while not FLOOR.has_point(point):
		point = center + Vector2.RIGHT.rotated(randf_range(0.0, TAU)) * radius
	return point

What's in the folder

  • spawner.gd: the Timer hookup, spawn_point and the FLOOR check (new in this episode)
  • arena.tscn: the Episode 3 arena plus the Spawner node and its SpawnTimer
  • enemy.gd and enemy.tscn: the crab, unchanged from Episode 3
  • spark.gd and spark.tscn: the spark, unchanged from Episode 3

Run it

  1. Install Godot 4.8 beta 1 (the standard build).
  2. Download the Episode 3 project above and unzip it.
  3. In Godot's Project Manager, click Import and pick project.godot inside the spark-swarm-ep03 folder.
  4. Add the Spawner from the steps above, then press Play (F5). Move with WASD, the arrow keys or a gamepad. Zap with Space or the bottom face button.

One honest limit: Nothing ever stops the count. Leave the game running and the crabs keep coming: after a minute there are sixty new crabs on the floor, and they never leave. Touching you still does nothing; getting hurt comes in a later episode.
