Episode 9 taught the score to count. But points are bragging — they don’t change the run. This episode gives every gem a second job: XP. Grabs fill a bar, the bar buys levels, and every level hands the spark twenty health back, mid-fight. One warning: the first version of this system pays you for dying. We fix that too.

What you build

  1. Give the spawner two more numbers: next to the score, it now owns xp and level (wave_spawner.gd below). One owner for the run’s books — Episode 8’s lesson, applied to growth.
  2. Price the levels with a formula, not a table: xp_needed(level) = 5 + (level - 1) x 2. Level 2 costs 5, level 3 costs 7 more, level 4 costs 9 more — and level 40 still works. XP left over after a level carries across the threshold; nothing is wasted.
  3. Count XP in the gem’s collected handler — and nowhere else. The first version hung XP on tree_exited, which fires for ANY exit: grabs, despawns, and the game-over restart sweeping gems off the floor. Two honest grabs plus three swept gems is five — the price of level 2, paid for dying. Count the grab, not the goodbye.
  4. Pay the level: crossing the price shouts level_up, and the spark hears its name (spark.gd below) — health goes up by the Level Heal export (20), clamped at max health, and a dead spark stays dead.
  5. Show the climb: a LevelLabel in the HUD (level_label.gd below) listens to xp_changed and prints the level and progress — LV 1 · XP 3/5 — popping a little when the level changes. Like Episode 8’s labels, it asks the spawner for the starting state, so it is never blank or wrong.

The wave spawner, with XP (wave_spawner.gd)

extends Node2D
## WaveSpawner — Spark Swarm Episode 10 ("Level Up").
##
## Ep5's wave spawner + Ep8's wave_progress + Ep9's loot and score,
## plus Ep10's growth: every collected gem also pays XP, XP fills
## the current level's price, and a filled price levels the spark
## up. The spawner owns the numbers and shouts the changes
## (xp_changed / level_up); the HUD label and the spark's heal
## listen. Levels live here, so a restart resets them with the
## score — Ep10's honest limit; saving is a later episode's job.
##
## Scene setup (unchanged from Ep5, plus the gem scene export):
##   WaveSpawner (Node2D, this script, in the "spawner" group)
##   ├── SpawnTimer (Timer, one_shot = true)  -> timeout -> _on_spawn_timer_timeout
##   └── BreakTimer (Timer, one_shot = true)  -> timeout -> _on_break_timer_timeout
## The crab scene, gem scene and arena are exported vars, set in
## the Inspector.

signal wave_started(wave_number: int, crab_count: int)
signal wave_cleared(wave_number: int)
## Ep8: the crabs-left count, announced on every change.
signal wave_progress(remaining: int)
## Ep9: shouted every time the score moves; the HUD listens.
signal score_changed(new_score: int)
## Ep10: shouted every time XP moves, with the current level's
## price, so the HUD label never has to ask twice.
signal xp_changed(xp: int, xp_needed_now: int, level: int)
## Ep10: shouted once per level gained, the moment it happens.
## The spark listens and patches itself up (spark.gd).
signal level_up(new_level: int)

## The crab scene, copied once per spawn (Episode 3/4).
@export var crab_scene: PackedScene
## The gem scene (Ep9), copied once per winning drop roll.
@export var gem_scene: PackedScene
## The arena node new crabs (and dropped gems) are added to, so they
## live in the world, not inside the spawner. (NodePath export: node
## exports assigned in a .tscn need the NodePath form to resolve.)
@export var arena: NodePath

## Crabs in wave 1.
@export var first_wave_size: int = 4
## Extra crabs each new wave adds.
@export var wave_growth: int = 2
## Seconds between crabs inside one wave.
@export var spawn_gap: float = 0.9
## Seconds of quiet between waves.
@export var break_length: float = 4.0
## The odds that one kill drops a gem. 0.25 is one in four.
@export var drop_chance: float = 0.25
## Points one collected gem is worth (Ep9's score).
@export var gem_value: int = 10
## XP one collected gem pays (Ep10). Score is the bragging;
## XP is the growing. Same gem, two pockets.
@export var xp_per_gem: int = 1
## XP the first level costs.
@export var xp_base: int = 5
## Extra XP each new level adds to its price. Levels get
## hungrier by two, the way waves get bigger by two.
@export var xp_growth: int = 2

var wave_number: int = 0
## The run's score (Ep9). Lives here, so a restart resets it.
var score: int = 0
## XP banked toward the current level's price (Ep10).
var xp: int = 0
## The spark's current level. Starts at 1.
var level: int = 1
var _to_spawn: int = 0  # crabs still owed by the current wave

@onready var _spawn_timer: Timer = $SpawnTimer
@onready var _break_timer: Timer = $BreakTimer


func _ready() -> void:
	# The first wave gets the same short break, so the player sees the
	# arena and the WAVE 1 banner before the first crab walks in.
	_break_timer.start(break_length)


## How many crabs a wave sends. Wave 1: 4, wave 2: 6, wave 3: 8.
func crabs_in_wave(wave: int) -> int:
	return first_wave_size + (wave - 1) * wave_growth


## Seconds one wave's spawning takes: the first crab is instant,
## every crab after it waits one gap. Wave 1: 3 x 0.9 = 2.7 s.
func spawn_span(wave: int) -> float:
	return (crabs_in_wave(wave) - 1) * spawn_gap


## Crabs the player still has to beat this wave — the ones on
## screen plus the ones this wave still owes (Episode 8).
func crabs_remaining() -> int:
	return _to_spawn + get_tree().get_nodes_in_group("enemies").size()


## On-average gems for a clear of this many crabs: kills times the
## chance. Wave 3: 8 x 0.25 = 2. An average, not a promise.
func expected_gems(crab_count: int) -> float:
	return crab_count * drop_chance


## The price of a level: a base, plus a growth — the wave formula
## wearing a new hat. Level 1 costs 5, level 2 costs 7, level 3
## costs 9.
func xp_needed(for_level: int) -> int:
	return xp_base + (for_level - 1) * xp_growth


## On-average XP for a clear of this many crabs: one XP rides
## every expected gem. Wave 3: 2 gems, 2 XP.
func expected_xp(crab_count: int) -> float:
	return expected_gems(crab_count) * xp_per_gem


func _on_break_timer_timeout() -> void:
	_start_wave()


func _start_wave() -> void:
	wave_number += 1
	_to_spawn = crabs_in_wave(wave_number)
	wave_started.emit(wave_number, _to_spawn)
	wave_progress.emit(crabs_remaining())
	_spawn_crab()  # the first crab of the wave arrives right away
	if _to_spawn > 0:
		_spawn_timer.start(spawn_gap)


func _on_spawn_timer_timeout() -> void:
	_spawn_crab()
	if _to_spawn > 0:
		_spawn_timer.start(spawn_gap)


func _spawn_crab() -> void:
	var crab = crab_scene.instantiate()
	crab.position = _spawn_point()
	get_node(arena).add_child(crab)
	# tree_exited fires when the crab leaves the tree (any reason),
	# which is the spawner's cue to check whether the wave is over.
	crab.tree_exited.connect(_on_crab_gone)
	# died fires only for a zap kill, and carries the spot where the
	# crab fell — that's the drop roll's one hookup. (The crab is
	# deliberately untyped here: died is the crab script's own
	# signal, not a Node2D one.)
	crab.died.connect(_on_crab_died)
	_to_spawn -= 1
	wave_progress.emit(crabs_remaining())


func _on_crab_gone() -> void:
	# During a scene reload (Ep7), a crab can leave the tree after
	# the spawner itself has already left it — get_tree() is null
	# then, and there is no wave left to check. Bail out quietly.
	if not is_inside_tree():
		return
	wave_progress.emit(crabs_remaining())
	# A wave is cleared when nothing is left to spawn AND no crab
	# from the group is still alive in the arena.
	if _to_spawn == 0 and get_tree().get_nodes_in_group("enemies").is_empty():
		wave_cleared.emit(wave_number)
		_break_timer.start(break_length)


## THE DROP ROLL (Ep9). Runs exactly once per kill, because died
## does. Random rewards roll at the event, never in a loop.
func _on_crab_died(at_position: Vector2) -> void:
	if randf() < drop_chance:
		_drop_gem(at_position)


func _drop_gem(at_position: Vector2) -> void:
	var gem = gem_scene.instantiate()
	gem.position = at_position
	get_node(arena).add_child(gem)
	gem.collected.connect(_on_gem_collected)


## A gem was GRABBED — the one moment money and growth are counted.
## Ep10's first version counted XP on the gem's tree_exited instead:
## floor gems "paid" their XP when a restart swept them out of the
## scene, and the spark leveled up by dying. Count the grab, not
## the goodbye.
func _on_gem_collected(_gem: Area2D) -> void:
	score += gem_value
	score_changed.emit(score)
	_gain_xp(xp_per_gem)


## Bank XP, then pay level prices while the bank covers them.
## Leftover XP carries into the next level — no step is wasted.
func _gain_xp(amount: int) -> void:
	if amount <= 0:
		return
	xp += amount
	while xp >= xp_needed(level):
		xp -= xp_needed(level)
		level += 1
		level_up.emit(level)
	xp_changed.emit(xp, xp_needed(level), level)


## A point just outside a random edge of the arena (Episode 4's rule:
## crabs walk in from off screen, from any edge).
func _spawn_point() -> Vector2:
	var rect := Rect2(Vector2(64, 64), Vector2(1024, 520))
	var margin := 48.0
	var edge := randi() % 4
	match edge:
		0:  # top
			return Vector2(randf_range(rect.position.x, rect.end.x), rect.position.y - margin)
		1:  # bottom
			return Vector2(randf_range(rect.position.x, rect.end.x), rect.position.y + margin)
		2:  # left
			return Vector2(rect.position.x - margin, randf_range(rect.position.y, rect.end.y))
		_:  # right
			return Vector2(rect.end.x + margin, randf_range(rect.position.y, rect.end.y))

The level label (level_label.gd)

extends Label
## LevelLabel — Spark Swarm Episode 10 ("Level Up").
##
## One new label in the Ep8 HUD's top-left stack, under the score:
## it shows the spark's level and the XP banked toward the next
## one ("LV 1 · XP 3/5"). Ep9's ScoreLabel with new ears — the
## spawner owns the numbers and shouts xp_changed; this label's
## whole job is: hear the shout, write the truth. On level_up it
## pops, so the moment catches the player's eye.
##
## Scene setup: a Label in the HUD's CanvasLayer with this script.
## The spawner is found through the "spawner" group — the same
## lookup Ep5's WaveBanner and Ep9's ScoreLabel use.

func _ready() -> void:
	var spawner := get_tree().get_first_node_in_group("spawner")
	if spawner != null:
		spawner.xp_changed.connect(_on_xp_changed)
		spawner.level_up.connect(_on_level_up)
		# Signals only announce changes, and nothing has changed
		# yet: ask for the starting state, once (the Ep8 HUD rule).
		_on_xp_changed(spawner.xp, spawner.xp_needed(spawner.level), spawner.level)


func _on_xp_changed(xp_now: int, xp_price: int, level_now: int) -> void:
	text = "LV %d · XP %d/%d" % [level_now, xp_now, xp_price]


func _on_level_up(_new_level: int) -> void:
	# A quick scale bounce around the label's centre, then settle.
	pivot_offset = size * 0.5
	scale = Vector2(1.35, 1.35)
	var tw := create_tween()
	tw.tween_property(self, "scale", Vector2.ONE, 0.25)

The spark, with the level-up heal (spark.gd)

extends CharacterBody2D
## Spark — the player (Episodes 1 + 3 + 6 + 7, series build;
## Ep10 adds the level-up heal).
## Eased movement (Ep1), fence clamp to the floor (Ep1), auto-aim zap
## that damages the nearest crab in range (Ep3). Zap feel: a line,
## a flash, a shake (Ep1). `autoplay` drives the spark for captures.
##
## Ep6 adds health: a crab touch costs health, a red flash shows the
## hit, and a half-second mercy cooldown means one touch is one hit.
## There is also no hit sound: the sound is saved for the juice episode.
##
## Ep7 adds the ending: when health reaches zero the spark shouts
## died, exactly once — the is_dead state flag remembers the run is
## over, so late hits (even two crabs on the same physics step)
## change nothing. The GameOver layer listens for the shout.
##
## Ep10 adds the level-up payoff: the spawner shouts level_up, the
## spark hears it (the "spawner" group lookup, Ep5's pattern) and
## patches itself up by level_heal. Picking what a level gives is
## Episode 11's job; in Ep10 the heal is the whole prize.

signal health_changed(new_health: int)
signal died

@export var speed: float = 300.0
@export var accel: float = 3000.0
@export var zap_range: float = 230.0
@export var zap_cooldown: float = 0.2
## Health the spark starts with. Ten clean crab hits empty it.
@export var max_health: int = 100
## Seconds after a landed hit during which the spark can't be hurt
## again. This cooldown belongs to the spark, not to any one crab,
## so a whole swarm shares the same speed limit.
@export var hit_cooldown: float = 0.5
## Health a level-up hands back (Ep10). Twenty is two hits' worth.
@export var level_heal: int = 20
@export var autoplay: bool = false

const FLOOR_MIN := Vector2(64, 64)
const FLOOR_MAX := Vector2(1088, 584)
const RADIUS := 20.0

var health: int
## Run state (Ep7): false while playing, true once the run is over.
var is_dead: bool = false

var _cooldown_left: float = 0.0
var _hit_left: float = 0.0
var _facing: Vector2 = Vector2.RIGHT

@onready var _sprite: Sprite2D = $Sprite
@onready var _zap_line: Line2D = $ZapLine
@onready var _flash: ColorRect = $FlashLayer/Flash


func _ready() -> void:
	health = max_health
	# Ep10: hear the level-up shout. Group membership is set in the
	# scene (the Groups-dock way), so the spawner is findable here
	# no matter which node's _ready runs first.
	var spawner := get_tree().get_first_node_in_group("spawner")
	if spawner != null and spawner.has_signal("level_up"):
		spawner.level_up.connect(_on_level_up)


func _physics_process(delta: float) -> void:
	_hit_left = maxf(_hit_left - delta, 0.0)
	var input_dir := Vector2.ZERO
	if autoplay:
		input_dir = _autoplay_dir()
	else:
		input_dir = Input.get_vector("move_left", "move_right", "move_up", "move_down")
	var target := input_dir * speed
	velocity = velocity.move_toward(target, accel * delta)
	move_and_slide()
	global_position.x = clampf(global_position.x, FLOOR_MIN.x + RADIUS, FLOOR_MAX.x - RADIUS)
	global_position.y = clampf(global_position.y, FLOOR_MIN.y + RADIUS, FLOOR_MAX.y - RADIUS)
	if input_dir != Vector2.ZERO:
		_facing = input_dir.normalized()
	_cooldown_left -= delta
	if _cooldown_left <= 0.0:
		var crab := _nearest_crab()
		if crab != null:
			_zap(crab)


## Something hurt the spark. Returns true when the hit counted, so
## the attacker knows it connected (the crab bounces off only then).
## While the mercy cooldown is still running, the hit is ignored:
## a touch that stays touching does not keep paying out.
func take_damage(amount: int) -> bool:
	if is_dead:
		return false  # dead is dead: late hits change nothing
	if _hit_left > 0.0:
		return false
	_hit_left = hit_cooldown
	health = clampi(health - amount, 0, max_health)
	health_changed.emit(health)
	_flash_damage()
	if health <= 0:
		is_dead = true  # set the flag BEFORE the shout,
		died.emit()     # so listeners already see the final state
	return true


## Patch the spark up (Ep10). The mirror of take_damage: never
## above max health, and never for the dead — a level-up that
## lands after the run ends changes nothing.
func heal(amount: int) -> void:
	if is_dead or amount <= 0:
		return
	var new_health := clampi(health + amount, 0, max_health)
	if new_health != health:
		health = new_health
		health_changed.emit(health)


func _on_level_up(_new_level: int) -> void:
	heal(level_heal)


func _flash_damage() -> void:
	# The damage feedback (Ep6): the sprite blinks red and settles
	# back over a quarter of a second. A tween, like the Ep5 banner.
	# No sound here — the hit sound is saved for the juice episode.
	_sprite.modulate = Color(1.0, 0.3, 0.3)
	var tw := create_tween()
	tw.tween_property(_sprite, "modulate", Color.WHITE, 0.25)


func _nearest_crab() -> Node2D:
	var best: Node2D = null
	var best_d := zap_range
	for node in get_tree().get_nodes_in_group("enemies"):
		var d := global_position.distance_to(node.global_position)
		if d < best_d:
			best_d = d
			best = node
	return best


func _autoplay_dir() -> Vector2:
	# Kite the nearest crab: hold about 150 px from it, strafing slowly,
	# so the zap stays in range and the picture keeps moving.
	var crab := _nearest_crab_any()
	if crab == null:
		return Vector2.ZERO
	var to_crab := crab.global_position - global_position
	var dist := to_crab.length()
	var radial := 0.0
	if dist > 170.0:
		radial = 1.0
	elif dist < 120.0:
		radial = -1.0
	var tangent := to_crab.normalized().orthogonal() * 0.6
	return (to_crab.normalized() * radial + tangent).normalized()


func _nearest_crab_any() -> Node2D:
	var best: Node2D = null
	var best_d := INF
	for node in get_tree().get_nodes_in_group("enemies"):
		var d := global_position.distance_to(node.global_position)
		if d < best_d:
			best_d = d
			best = node
	return best


func _zap(crab: Node2D) -> void:
	_cooldown_left = zap_cooldown
	_facing = (crab.global_position - global_position).normalized()
	# The line: a jagged bolt to the crab (Ep1).
	var pts: PackedVector2Array = [Vector2.ZERO]
	var dir := _facing
	var side := dir.orthogonal()
	var dist := global_position.distance_to(crab.global_position)
	for i in range(1, 4):
		var along := dist * i / 4.0
		pts.append(dir * along + side * randf_range(-13.0, 13.0))
	pts.append(dir * dist)
	_zap_line.points = pts
	_zap_line.visible = true
	# The flash (Ep1): alpha 0.25, gone in a tenth of a second.
	_flash.modulate.a = 0.25
	var tw := create_tween()
	tw.tween_property(_flash, "modulate:a", 0.0, 0.1)
	tw.parallel().tween_callback(func() -> void: _zap_line.visible = false).set_delay(0.08)
	# The hit (Ep3): one zap, one crab down.
	if crab.has_method("take_hit"):
		crab.take_hit()

Run it

  1. Install Godot 4.8 beta 1 (the standard build).
  2. Unzip ep10.zip.
  3. In Godot’s Project Manager, click Import and pick project.godot inside the spark-swarm-ep10 folder.
  4. Press Play (F5). Move with WASD, the arrow keys or a gamepad. Zap with Space or the bottom face button.

One honest limit: The XP and the level live in the spawner, and a restart reloads the scene — so the climb resets with the run, same as the score. What a level-up should let you choose is the next episode’s job.

How it’s made

Every project is then built, run and tested in the real Godot 4.8 beta 1 editor, and the files here match the code shown in the video.
