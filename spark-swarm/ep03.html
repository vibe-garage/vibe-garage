What you build

  1. Make an enemy: a CharacterBody2D with the Kenney Tiny Dungeon red crab and a 24 px collision circle.
  2. Teach it to chase: enemy.gd with a speed and a target, walking straight at whatever it noticed.
  3. Give it senses: an Area2D Sense ring about 3 tiles wide, and a body_entered signal that wakes the crab.
  4. Aim the zap: put crabs in the enemies group, find the nearest one within 220 px, and queue_free on hit.
  5. Fill the arena with five crab instances from the same scene.
  6. Hunt the sleepwalkers: a first draft that targets anything the Sense notices, then fix it so the crab only takes a target in the player group.
  7. Hunt them down: the bolt always takes the nearest crab first.
  8. Run the same hunt in a browser tab on your own computer.

The auto-aimed zap (spark.gd)

func nearest_enemy() -> Node2D:
	var nearest: Node2D = null
	var best := zap_length
	for enemy: Node2D in get_tree().get_nodes_in_group("enemies"):
		var distance := global_position.distance_to(enemy.global_position)
		if distance < best:
			best = distance
			nearest = enemy
	return nearest

What's in the folder

  • enemy.gd: chase and the Sense callback
  • enemy.tscn: the crab scene: sprite, body, Sense area
  • spark.gd: Episode 2's code plus nearest_enemy and an aimed zap
  • spark.tscn: the spark, now in group player
  • arena.tscn: the Episode 2 arena with five crab instances

Run it

  1. Install Godot 4.8 beta 1 (the standard build).
  2. Unzip ep03.zip.
  3. In Godot's Project Manager, click Import and pick project.godot inside the spark-swarm-ep03 folder.
  4. Press Play (F5). Move with WASD, the arrow keys or a gamepad. Zap with Space or the bottom face button.

One honest limit: Crabs walk straight at you, and nothing steers them around anything. Put a pillar between you, and the crab presses into the bricks and stays there.

How it's made

How this series is made: Lexi Volt's narration voice is AI-generated, and the scripts, the music and the project code were written with AI tools. Every project is then built, run and tested in the real Godot 4.8 beta 1 editor, and the files here match the code shown in the video. The tiles and the zap sound are free CC0 assets by Kenney.
