Episode 10 made your gems count: every grab pays XP, and XP buys levels. But a level that only raises a number changes nothing. This episode makes the level a decision — the fight freezes, three cards hit the table, and the one you pick rewrites the spark’s numbers on the spot. One warning: the first build of the choice panel is a trap. The cards show up, and every button is dead. We fix that too — with one Inspector setting.

What you build

  1. Build the stage: a CanvasLayer named PowerUpLayer — Episode 7’s game-over layer is the pattern — holding a Panel that starts hidden, a Dim, a Title, and a row of three Buttons.
  2. Write the choices as data: one CHOICES list of dictionaries (an ID, a name, one line of what changes). In _ready, each button’s text is set from that data and every pressed signal connects to one function, choose, with the choice’s ID bound in — so the card can never say one thing and do another.
  3. Hook the level: the layer finds the spawner by its spawner group (Episode 5’s lookup) and connects Episode 10’s level_up signal. When it fires, the title names the level, the panel shows, and get_tree().paused = true freezes the fight.
  4. Survive the trap: a paused tree pauses every node that inherits its Process Mode — including the layer, so its own buttons die. Set the layer’s Process Mode to Always (the Inspector; Episode 7’s fix) and it stays awake while the world sleeps. Freeze the fight, never the referee.
  5. Apply the pick: one function reaches the spark through the player group and multiplies a setting — Rapid Zap halves zap_cooldown (0.20 → 0.10, five zaps a second → ten), Wide Zap multiplies zap_range by 1.5 (230 → 345), Gem Magnet doubles magnet_radius (90 → 180). Picks stack: a second Rapid halves again, to 0.05 — twenty a second.

The choice layer (power_up_layer.gd)

extends CanvasLayer
## PowerUpLayer — Spark Swarm Episode 11 ("Power Up").
##
## When the spawner shouts level_up (Ep10), this layer freezes the
## fight and offers three power-ups as cards. The pick is applied
## to the spark's settings, the panel closes, and the tree unpauses.
##
## Scene setup (built in the episode):
##   PowerUpLayer (CanvasLayer, this script)
##     Process Mode: Always (set in the Inspector) — THE EPISODE'S
##     BUG AND FIX. The first build left this at Inherit: the panel
##     showed, the tree paused, and the layer paused with it, so
##     every button was dead and the run soft-locked behind glass.
##     Always means the layer (and its buttons, which inherit from
##     it) keeps working while the world stays frozen — Episode 7's
##     game-over lesson, one episode early and one layer over.
##   └── Panel (Control, full rect, starts hidden)
##       ├── Dim (ColorRect, full rect, black, alpha 0.55)
##       ├── Title (Label, "LEVEL 2 — PICK ONE", set in code)
##       └── Cards (HBoxContainer)
##           ├── Button (text set in code from CHOICES)
##           ├── Button
##           └── Button
##
## The choices are data, not scenes: one dictionary per card, and
## the buttons' text is written from it in _ready, so what a card
## says can never drift from what the pick does.

const CHOICES: Array = [
	{"id": "rapid", "title": "RAPID ZAP", "blurb": "Zap twice as fast"},
	{"id": "wide", "title": "WIDE ZAP", "blurb": "Zap reaches half again as far"},
	{"id": "magnet", "title": "GEM MAGNET", "blurb": "Gems lean in from twice as far"},
]

@onready var _panel: Control = $Panel
@onready var _title: Label = $Panel/Title
@onready var _cards: HBoxContainer = $Panel/Cards

## Levels whose choice is still owed. A level can't land while the
## tree is paused (no XP flows), so this is 1 in real play; the
## queue exists so a multi-level grant can never eat a pick.
var _pending: Array[int] = []


func _ready() -> void:
	_panel.hide()
	# The cards say what the data says.
	var buttons := _cards.get_children()
	for i in buttons.size():
		var button := buttons[i] as Button
		var choice: Dictionary = CHOICES[i]
		button.text = "%s\n%s" % [choice["title"], choice["blurb"]]
		button.pressed.connect(choose.bind(choice["id"]))
	# The banner found the spawner by its group in Episode 5;
	# the level display did the same in Episode 10.
	var spawner := get_tree().get_first_node_in_group("spawner")
	if spawner != null:
		spawner.level_up.connect(_on_level_up)


func _on_level_up(new_level: int) -> void:
	_pending.append(new_level)
	if _panel.visible:
		return  # a choice is already open; this one queues behind it
	_open_choice()


func _open_choice() -> void:
	_title.text = "LEVEL %d — PICK ONE" % _pending[0]
	_panel.show()
	# Freeze the fight. The layer itself stays awake (Process Mode:
	# Always) so the buttons can be clicked; nothing else moves.
	get_tree().paused = true


## One function for all three picks: the ID says which, the
## function does the rest. Connected to every card's pressed
## signal in _ready, with the ID bound in.
func choose(choice_id: String) -> void:
	_apply_power_up(choice_id)
	_pending.pop_front()
	if not _pending.is_empty():
		_open_choice()  # another level is owed its pick; stay frozen
		return
	_panel.hide()
	get_tree().paused = false


## The whole power-up system: three settings on the spark, reached
## through the player group (Episode 3's targeting group). Picks
## stack — the same card picked at a later level applies again.
func _apply_power_up(choice_id: String) -> void:
	var spark := get_tree().get_first_node_in_group("player")
	if spark == null:
		return
	match choice_id:
		"rapid":
			# 0.20 -> 0.10 -> 0.05 ... five zaps a second -> ten.
			spark.zap_cooldown *= 0.5
		"wide":
			# 230 -> 345 -> ... half again as far, every pick.
			spark.zap_range *= 1.5
		"magnet":
			# 90 -> 180 -> 360 ... the gems' pull reaches twice as
			# far, every pick. (No zap setting is ever touched: one
			# zap stays one hit, the rule Ep12's boss relies on.)
			spark.magnet_radius *= 2.0

Run it

  1. Install Godot 4.8 beta 1 (the standard build).
  2. Unzip ep11.zip.
  3. In Godot’s Project Manager, click Import and pick project.godot inside the spark-swarm-ep11 folder.
  4. Press Play (F5). Move with WASD, the arrow keys or a gamepad. Zap with Space or the bottom face button. Bank five gems and the first choice is yours.

One honest limit: a power-up lasts for the run, not forever. The picks live on the spark’s settings, a restart reloads the scene, and the scene file is the reset list — 0.20, 230, 90, factory numbers. Keeping a build between runs is saving, and saving is a later episode’s job.

Make it yours

Add a fourth dictionary to CHOICES and one branch to the match — say, a heal — and it deals itself: the data drives the card, the button, and the pick. Then play two runs back to back, one all-Rapid, one all-Magnet, and feel how different the same waves play.
