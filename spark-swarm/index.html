Spark Swarm

Make your first game in Godot 4.8. A free 14-episode beginner series that builds a survivors-style arena game from an empty folder, one playable step at a time. No experience needed.

How it works

  1. Watch an episode and build along in Godot 4.8 beta 1.
  2. Stuck, or want to skip ahead? Download that episode's zip, or browse it on GitHub.
  3. Change something, then post your version from the episode page.

How it's made

How this series is made: Lexi Volt's narration voice is AI-generated, and the scripts, the music and the project code were written with AI tools. Every project is then built, run and tested in the real Godot 4.8 beta 1 editor, and the files here match the code shown in the video. The tiles and the zap sound are free CC0 assets by Kenney.
