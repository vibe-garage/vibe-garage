Your game knows everything and shows nothing. The spark's health, the wave you're on, and how many crabs are left all exist — invisibly. In this episode you build the heads-up display that says them out loud: pips that go dark when you're hit, the wave number, and a crabs-left count that never lies.

What you build

  1. Lay out the HUD on Episode 5's CanvasLayer: a Control named HUD set to Full Rect anchors, a VBox top-left holding the Wave and Crabs Left labels, and an HBox of ten ColorRect pips top-right with Grow Horizontal set to Begin.
  2. Set Mouse Filter to Ignore on the whole HUD tree — a HUD that eats clicks is a bug with good graphics, so input passes straight through to the game.
  3. Wire it to the shouts: hud.gd finds the spawner and the spark from two Inspector NodePaths and connects the spawner's wave_started and wave_cleared and the spark's health_changed.
  4. Draw health as pips: Episode 6's model is 100 health at 10 per hit, so the first health ÷ 10 pips stay lit and the rest go dark — one pip per hit, exactly.
  5. Ask once at the start: signals only announce changes, and nothing has changed yet, so in _ready the HUD asks for the starting health and crabs_remaining() once. After that it never asks again — it listens.
  6. Catch the counting bug: version one counted the enemies group in _process, sixty times a second. That count can only see crabs that already exist — at the start of wave 2 it read CRABS LEFT: 1 while five more were still owed, and the number climbed while the player was winning.
  7. The fix: the spawner gains crabs_remaining() — owed plus alive, both halves of the truth — and a wave_progress signal shouted on wave start, on every spawn, and on every death. The HUD subscribes, the cheat is deleted, and wave 2 opens at CRABS LEFT: 6 and only ever falls.

The HUD only listens (hud.gd)

func _ready() -> void:
	_ignore_mouse(self)
	if spawner_path.is_empty() or player_path.is_empty():
		push_warning("HUD: spawner_path and player_path must be set in the Inspector.")
		return
	_spawner = get_node(spawner_path)
	_player = get_node(player_path)
	# Subscribe to the shouts (signals from Episodes 5, 6 and 8).
	_spawner.wave_started.connect(_on_wave_started)
	_spawner.wave_cleared.connect(_on_wave_cleared)
	_spawner.wave_progress.connect(_on_wave_progress)
	_player.health_changed.connect(_on_health_changed)
	# Signals only announce changes, and nothing has changed yet:
	# ask both systems for the starting state, once. After this,
	# the HUD never asks again — it listens.
	_on_health_changed(_player.health)
	_on_wave_progress(_spawner.crabs_remaining())


func _on_wave_progress(remaining: int) -> void:
	_crabs_label.text = "CRABS LEFT: %d" % remaining


## Pips are the health number, drawn: health is counted in tens
## (Episode 6: 100 health, 10 per hit), so the first health / 10
## pips stay lit and the rest go dark.
func _on_health_changed(new_health: int) -> void:
	var lit := new_health / 10
	var pips := _hearts.get_children()
	for i in pips.size():
		(pips[i] as ColorRect).modulate.a = 1.0 if i < lit else 0.25

What's in the folder

  • hud.gd: the HUD — Inspector paths to the spawner and spark, the signal hookups, the pips loop (new in this episode)
  • wave_spawner.gd: Episode 5's wave system, plus crabs_remaining() and the wave_progress signal (new in this episode)
  • spark.gd: Episodes 1–7, with the health_changed and died signals the HUD and game over screen listen to
  • game_over.gd and wave_banner.gd: Episode 7's ending and Episode 5's banner, unchanged
  • arena.tscn: the arena scene, now with the HUD on the CanvasLayer and its two Inspector paths assigned

Run it

  1. Install Godot 4.8 beta 1 (the standard build).
  2. Unzip ep08.zip.
  3. In Godot's Project Manager, click Import and pick project.godot inside the spark-swarm-ep08 folder.
  4. Press Play (F5). Move with WASD, the arrow keys or a gamepad. Zap with Space or the bottom face button.

One honest limit: the HUD shows facts, not the fight. It can only report what the game shouts — a crab creeping up behind you is not in any fact on screen, and the HUD sits correct and useless for that one thing. From here on, every new system gets a signal, not a readout.

Run wave 4 and predict the corner before the first crab walks in: three crabs still owed and four on screen — what does the HUD say is left? (Seven: 3 + 4. And wave 4 sends ten in all: 4 + 3 × 2.) Then watch whether your count ever climbs. If it does, your screen is guessing.
